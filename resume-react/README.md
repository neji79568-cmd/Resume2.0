# Простое резюме

Одна страница на React: фото, имя, информация о себе, навыки, образование, проекты и контакты.

На этом компьютере откройте `start.cmd`. Или установите Node.js 24 LTS и выполните:

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Готовый сайт находится в `dist/`.

Информация редактируется в `src/data.js`, разметка — в `src/App.jsx`, оформление — в `src/styles.css`. Фото — `public/photo.jpg`.

Данные взяты из GitHub [neji79568-cmd](https://github.com/neji79568-cmd) и [Elgiz-Resume](https://github.com/neji79568-cmd/Elgiz-Resume). Фото скопировано из файла `Elgiz.jpg`, указанного в прежнем резюме.

Кнопка «Печать / PDF» открывает диалог печати браузера. Чтобы получить PDF, выберите «Сохранить как PDF».
